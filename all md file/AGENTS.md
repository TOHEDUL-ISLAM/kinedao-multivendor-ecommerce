## Overview

Multivendor baby products marketplace (Bangla/English). Bun monorepo: React/TanStack Start frontend + Hono API + shared packages.

## Structure

```
kineDao.com/
├── apps/
│   ├── web/           # React + TanStack Start (port 3001)
│   └── server/        # Hono API (port 3000)
├── packages/

│   ├── db/            # Drizzle schema + client
│   ├── env/           # Zod-validated env (server/web)
│   └── config/        # Shared tsconfig base
```

## Conventions

- **Filenames**: kebab-case (`product-card.tsx`, `forgot-password.tsx`)
- **Imports**: Use `@kineDao.com/*` for packages, `@/` for web app paths
- **Styling**: TailwindCSS utilities only, use `cn()` for class merging
- **State**: Zustand with `persist` middleware for client state
- **i18n**: All UI text via `t("key")` from `useTranslation` hook
- **Commits**: Conventional Commits (`feat:`, `fix:`, `chore:`) with optional scopes

## Anti-Patterns (This Project)

| Pattern | Why Forbidden |
|---------|---------------|
| Modify `packages/db/src/schema/auth.ts` | Auto-generated by Better-Auth |
| Commit `.env` files | Contains secrets |
| Hard-coded UI strings | Must use translation keys |
| `as any`, `@ts-ignore` | Strict TypeScript enforced |
| Direct DB queries in components | Use server routes or server functions |

## Unique Styles

- **Currency**: Always display `৳` (Taka) via `formatPrice()` in `apps/web/src/lib/format.ts`
- **Bilingual**: Bangla (`bn`) and English (`en`) required for all user-facing text
- **Cookies**: Better-Auth uses `sameSite: "none"`, `secure: true`, `httpOnly: true`
- **Email links**: Dev URLs rewrite port 3000→3001 in auth callbacks

## Commands

```bash
# Development
bun install              # Install deps
bun run dev              # Start all (web + server)
bun run dev:web          # Frontend only (localhost:3001)
bun run dev:server       # API only (localhost:3000)

# Database
bun run db:push          # Push schema changes (dev)
bun run db:generate      # Generate migrations
bun run db:migrate       # Apply migrations (prod)
bun run db:studio        # Drizzle Studio GUI
bun run db:seed          # Seed sample data

# Quality
bun run check-types      # TypeScript check all packages
bun run build            # Build all apps
```

## Notes

- **No ESLint/Prettier**: lint-staged is configured but disabled. Type-checking is the baseline.
- **Server start**: `apps/server/src/index.ts` exports app but doesn't call `listen()`. Bun handles this.
- **Auth flow**: Better-Auth mounted at `/api/auth/*`. Frontend uses `authClient` from `better-auth/react`.
- **packages/api**: Referenced in docs but doesn't exist. Business logic lives in server routes.
- **Root package.json**: Contains `catalog:` dependency syntax (Bun workspace catalogs).
