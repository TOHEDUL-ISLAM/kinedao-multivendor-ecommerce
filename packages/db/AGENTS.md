# Database Package Knowledge Base (packages/db)

## Overview

Drizzle ORM + PostgreSQL. Exports `db` instance and schema tables.

## Structure

```
src/
├── index.ts          # db = drizzle(DATABASE_URL, { schema })
└── schema/
    ├── index.ts      # Re-exports all tables
    ├── auth.ts       # ⚠️ AUTO-GENERATED (Better-Auth)
    ├── vendors.ts    # Vendor accounts
    ├── categories.ts # Product categories
    ├── products.ts   # Products + images
    └── campaigns.ts  # Marketing campaigns
```

## Anti-Patterns

| Pattern | Why |
|---------|-----|
| **Modify `auth.ts`** | Auto-generated by Better-Auth. Changes will be overwritten. |
| Direct env access | Use `@kineDao.com/env/server` |
| Skip schema export | Tables won't be included in Drizzle instance |

## Adding a New Table

1. Create `src/schema/new-table.ts`:
```typescript
import { pgTable, text, timestamp } from "drizzle-orm/pg-core";

export const newTable = pgTable("new_table", {
  id: text("id").primaryKey(),
  createdAt: timestamp("created_at").defaultNow().notNull(),
  updatedAt: timestamp("updated_at").defaultNow().notNull().$onUpdate(() => new Date()),
});
```

2. Export from `src/schema/index.ts`:
```typescript
export * from "./new-table";
```

3. Push to database:
```bash
bun run db:push
```

## Schema Patterns

- **IDs**: Use `text("id").primaryKey()` with cuid or uuid
- **Timestamps**: `createdAt` with `defaultNow()`, `updatedAt` with `$onUpdate()`
- **Relations**: Define in same file using `relations()` helper
- **Indexes**: Add via `index("idx_name").on(table.column)`

## Imports

```typescript
// In server routes:
import { db } from "@kineDao.com/db";
import { products, categories } from "@kineDao.com/db/schema";

// Query example:
const result = await db.select().from(products).where(eq(products.id, id));
```

## Commands

```bash
bun run db:push      # Push schema (dev)
bun run db:generate  # Generate migration
bun run db:migrate   # Run migrations
bun run db:studio    # Open Drizzle Studio
bun run db:seed      # Seed sample data
```
